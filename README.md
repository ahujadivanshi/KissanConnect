# KisanConnect — Free Hackathon Prototype

A responsive farmer-to-buyer marketplace demo built with plain HTML, CSS and JavaScript. No installation, API key, or paid service is required.

## Run it
1. Extract `KisanConnect.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or another browser.
3. Try Crop prices, List a crop, and Find buyers.

## Included interactions
- Crop-price filtering and sorting
- Sample price-trend chart
- Farmer crop-listing form
- Buyer search by crop, location and quantity
- Simple possible-match display

## Important demo limitations
- All crop prices and buyer profiles are illustrative sample data, not live market information.
- Listings exist only in the current browser session and are not sent to a server.
- Buyer profiles are fictional demo profiles; the prototype does not facilitate real transactions.
- For a production app, add secure backend storage, verified market data, authentication, and consent-based contact features.
